# Matching notes: SDK platform state

Filesystem and load-file version checks compare all four bytes of the
builtin tag. The TTY flag, top-thread ID and line index are signed words
read and updated by their existing libkernl callers. The native sbrk
helper advances a heap-end address starting at the original linker
symbol. The character sink starts at serialPutchar; the debug print
wrapper temporarily swaps in deci2Putchar through the same signature.

Removing any section attribute alone moves precisely that object to
.sdata in both stock modes. The raw prefix retains its original 16 bytes;
the six new source objects retain both native pointer relocations and
their exact 24-byte span, confirmed at retail addresses in both modes.
