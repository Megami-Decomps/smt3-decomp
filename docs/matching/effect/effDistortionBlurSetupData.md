# Matching notes: distortion blur editor setup

The native menu has fifteen existing items and saves all 44 bytes of its
live parameter record. The editor's create, update, destroy and recreate
slots pass object pointers through the shared editor callback interface.
The implementations recover their concrete parameter or resource type at
entry. The direct field and effect callers use the same declarations.

The automap initializes the existing eleven-word parameter layout with
the same values, including a zero floating-point rotation. Both stock
build modes preserve every allocated section and relocation of all six
provider and reader units. The standalone descriptor has 64 native bytes
and the original nine named address references.
